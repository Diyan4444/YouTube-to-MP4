Overview & Motivation
This application is a local, lightweight media downloader created to solve a common travel inconvenience. While attempting to download videos for 
offline viewing during a flight, existing web-based solutions proved frustrating due to intrusive advertisements and poor user experience.
To address this, I developed a clean, ad-free tool for personal offline access. Currently, the project operates entirely in a local environment, 
with plans for public deployment once cloud server infrastructure is established.
